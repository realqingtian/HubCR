# D-001 产品模式

[English](d-001-product-mode.md) | **简体中文**

- 状态：`ACCEPTED`
- 批准日期：2026-08-01
- 决策负责人：产品负责人
- 阻塞内容：身份与仓库发现契约

## 背景

公共 SaaS 需要滥用控制、账号恢复、内容治理和运维策略，这些能力目前都在 Registry
MVP 之后。

## 决策

MVP 优先私有化/自托管部署。实例可以暴露明确标记的公开仓库，但将 HubCR 作为公共
多租户 SaaS 运营的能力延后。

## 备选方案

- 公共 SaaS 优先：最接近 Docker Hub，但会把公网服务控制提前拉入 M1。
- 同等优先：在任一模式尚未得到验证前扩大配置与验收范围。

## 后果

M1 可以围绕实例运维者优化 Bootstrap 与管理。公网注册、计费、滥用防护和内容治理
保持不可用。
