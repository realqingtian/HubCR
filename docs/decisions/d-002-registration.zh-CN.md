# D-002 注册模式

[English](d-002-registration.md) | **简体中文**

- 状态：`ACCEPTED`
- 批准日期：2026-08-01
- 决策负责人：产品负责人
- 阻塞内容：用户生命周期 Schema 与注册 UI

## 背景

MVP 需要以受控方式创建用户，同时不能假装邮件投递、验证、恢复或公网滥用控制已经
存在。

## 决策

MVP 使用管理员邀请。授权管理员创建一次性、会过期的邀请，并通过系统外渠道交付。
匿名自主注册和可配置注册模式延后。

## 备选方案

- 开放自主注册：在安全暴露到公网前需要限流、验证、恢复和滥用控制。
- 可配置模式：会给 M1 增加多套生命周期契约与 UI 分支。

## 后果

M1 必须建模邀请签发、过期、兑换和撤销。邀请 Secret 只在创建时展示，并以 Hash
存储。
